FindBack — Smart Lost-and-Found Database

About:
FindBack is a MySQL database project designed to manage lost and found items in a college campus environment. It helps organize item reports, claims, and returns.

Features:
- Record lost and found item reports
- Categorize items and record their locations
- Search for potential matches between lost and found items
- Manage claims and claim statuses
- Track returned items
- Generate reports using SQL queries and joins

Database Tables:
- "Users" — stores user details
- "Categories" — stores item categories
- "Locations" — stores campus locations
- "ItemReports" — stores lost and found reports
- "Claims" — stores claims for reported items
- "Returns" — records returned items

Technologies Used:
- MySQL 8.0
- MySQL Command Line Client

How to Use:
1. Download "FindBack.sql" from this repository.
2. Open MySQL 8.0 Command Line Client.
3. Run the SQL script to create the database, tables, sample data, and queries.
